# Récits utilisateur

## US-001 — Demande numérique
**En tant que** client  
**Je veux** compléter une demande de compte en ligne  
**Afin de** ne pas avoir à répéter mes informations en agence.

## US-002 — Validation KYC
**En tant que** analyste de la conformité  
**Je veux** voir les résultats KYC et les anomalies  
**Afin de** examiner les dossiers nécessitant une intervention humaine.

## US-003 — Statut de la demande
**En tant que** client  
**Je veux** voir le statut de ma demande  
**Afin de** savoir si une action supplémentaire est requise.

## Critères d'acceptation — US-002
- Un filtrage terminé comporte un horodatage et une décision.
- Une anomalie est acheminée vers la file de conformité.
- Le client ne peut pas voir les notes internes d'examen.
