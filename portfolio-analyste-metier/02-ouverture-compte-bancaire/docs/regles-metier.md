# Règles métier

- BRULE-001 : les champs d'identité obligatoires doivent être complets avant le filtrage.
- BRULE-002 : une validation de document d'identité en échec ne peut pas être approuvée automatiquement.
- BRULE-003 : une anomalie de filtrage exige un examen humain.
- BRULE-004 : chaque décision finale doit donner lieu à un événement d'audit.
- BRULE-005 : les notes internes de conformité ne sont pas exposées aux clients.
