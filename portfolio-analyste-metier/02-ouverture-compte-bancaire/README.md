# Analyse de l'ouverture de compte bancaire numérique

## Contexte métier
Une banque souhaite numériser l'ouverture de compte client tout en préservant les contrôles KYC (connaissance client).

## Problème
Les candidats fournissent leurs informations via plusieurs étapes déconnectées. Les équipes de conformité manquent d'une vue standardisée des exceptions.

## Objectifs
- Définir un parcours d'onboarding numérique clair.
- Séparer le traitement normal des exceptions KYC.
- Formaliser les règles métier et les points de décision.
- Fournir des exigences testables à une équipe d'implémentation.

## Parties prenantes
Client, KYC/Conformité, Opérations, Équipe fraude, IT, Produit.

## Livrables
- Exigences
- Récits utilisateur
- Règles métier KYC
- Workflow AS-IS / TO-BE
- Cas d'utilisation de style UML
- Diagramme de séquence
- Exemples SQL / KPI
- Scénarios UAT

> Étude de cas synthétique. Aucune donnée bancaire ou personnelle réelle n'est utilisée.
