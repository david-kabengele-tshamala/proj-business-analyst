# Analyse des performances commerciales et des KPI métier

## Question métier
La direction souhaite comprendre la performance du chiffre d'affaires par catégorie de produit, par région et par mois.

## Perspective BA
L'objectif n'est pas seulement d'interroger les données. L'analyste définit d'abord :
1. les questions métier,
2. les définitions des KPI,
3. les règles de calcul,
4. les exigences relatives aux données,
5. les hypothèses et limites,
6. la décision / le cas d'utilisation de chaque métrique.

## Dictionnaire des KPI

| KPI | Définition |
|---|---|
| Chiffre d'affaires | Somme du revenu des commandes |
| Panier moyen | Chiffre d'affaires / nombre de commandes |
| Commandes | Nombre de commandes distinctes |
| Taux d'annulation | Commandes annulées / total des commandes |
| Chiffre d'affaires par région | Chiffre d'affaires groupé par région |
