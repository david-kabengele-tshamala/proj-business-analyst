# Check-list de validation des données

- [ ] Les identifiants de commande sont uniques là où c'est attendu.
- [ ] Le revenu est numérique.
- [ ] Les dates sont valides.
- [ ] Les valeurs de région correspondent à la liste de référence.
- [ ] Les valeurs de catégorie correspondent à la liste de référence.
- [ ] Les formules de KPI sont documentées.
- [ ] Les commandes annulées sont traitées de manière cohérente.
