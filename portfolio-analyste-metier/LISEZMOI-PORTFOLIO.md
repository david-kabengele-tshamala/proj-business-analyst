# Portfolio GitHub d'analyste métier (Business Analyst)

Un portfolio de 3 projets conçu pour un profil **d'analyste métier IT / analyste métier technique**.

## Projets

1. `01-gestion-commandes-ecommerce` — exigences, BPMN/UML, récits utilisateur, UAT et SQL.
2. `02-ouverture-compte-bancaire` — analyse de processus numérique, règles KYC, UML, exigences et UAT.
3. `03-analyse-donnees-ventes` — compétences BA + Data : définitions de KPI, SQL, qualité des données et données synthétiques.

## Présentation GitHub recommandée

Épinglez ces trois dépôts et faites en sorte que chaque LISEZMOI réponde aux questions :
- Quel est le problème métier ?
- Qui sont les parties prenantes ?
- Qu'est-ce qui est dans / hors périmètre ?
- Quelles exigences ont été identifiées ?
- Quels changements de processus sont proposés ?
- Comment les exigences peuvent-elles être testées ?
- Quelles données / KPIs étayent l'analyse ?

## Titre de profil GitHub suggéré

`Analyste métier IT | Ingénierie des exigences | BPMN/UML | SQL | Analyse des processus métier`

## Compétences démontrées

**Analyse métier :** ingénierie des exigences, analyse des parties prenantes, cartographie des processus, règles métier, récits utilisateur, critères d'acceptation, cas d'utilisation, analyse d'écarts / analyse de problèmes, UAT.

**Technique :** SQL, concepts de modélisation des données, réflexion API / processus, UML, Mermaid, qualité des données.

**Documentation :** BRD (cahier des charges métier), FRD (spécification fonctionnelle), dictionnaire de KPI, cas de test, esprit de traçabilité.

> Tous les cas et toutes les données sont des éléments synthétiques de portfolio.
