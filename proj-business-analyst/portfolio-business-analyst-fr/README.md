# Portfolio GitHub — Business Analyst IT

Trois études de cas conçues pour présenter une démarche professionnelle de **Business Analysis / Analyse métier IT**.

## Projets

| Projet | Orientation |
|---|---|
| `01-analyse-gestion-commandes-ecommerce` | Processus, exigences, UML/BPMN, UAT, SQL |
| `02-analyse-ouverture-compte-bancaire` | Processus métier, règles, exceptions, exigences, UAT |
| `03-analyse-performance-commerciale` | Business Analysis + SQL + KPI + qualité des données |

## Démarche commune

```text
Problème métier
      ↓
Parties prenantes
      ↓
Périmètre
      ↓
Processus AS-IS
      ↓
Processus TO-BE
      ↓
Exigences
      ↓
User Stories
      ↓
Règles métier
      ↓
BPMN / UML
      ↓
SQL / Données
      ↓
UAT
```

Les cas, noms et données sont synthétiques et destinés à la démonstration de compétences.
